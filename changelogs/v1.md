# Changelog - v1

All notable changes to `ts-mailkit` in version 1.x are documented here.

---

## [1.1.0] - 2026-09-20

### Added

- **Parameter Object Pattern for `EmailTemplateFactory`**:
  - `createEmailVerification(params: EmailVerificationParams)`, `createPasswordReset(params: PasswordResetParams)`, `createSimpleMessage(params: SimpleMessageParams)`, `createNewsLetter(params: NewsletterParams)`, `create2FAEmail(params: TwoFactorParams)`, `createMagicLinkEmail(params: MagicLinkParams)` (instance + static).

### Deprecated

- Positional signatures renamed to `*_Legacy` (e.g. `createEmailVerification_Legacy(...)`) with `@deprecated` tags. Will be removed in the next major release (v2).

## [1.0.0] - 2026-09-20

### Breaking Changes

- **Removed `ZeptoMailSender` & `ZeptoMailConfig`**:
  - Removed deprecated aliases in favor of `ZeptoMailHttpSender` and `ZeptoMailHttpConfig`.
- **Removed `sendEmail(...)` on `ZeptoMailHttpSender`**:
  - Removed legacy method `sendEmail(...)`. Transports strictly implement `IEmailSender.send(options: SendMailOptions)`.
- **Removed Positional `send(...)` Signature on `MailKit`**:
  - Removed `mailer.send(to, template, toName)`.
  - Use options object: `mailer.send({ to, template, ... })`.
- **Removed `sendSimpleMessage(...)` & `buildPlainTextMessage(...)`**:
  - Removed `mailer.sendSimpleMessage(...)` in favor of `mailer.sendRaw({ to, subject, html, text? })`.
  - Removed `mailer.buildPlainTextMessage(...)` in favor of `mailer.render(template)` or `buildPlainText(template)`.
- **Removed `EmailService` Alias**:
  - Removed deprecated `EmailService` export. Use canonical client class `MailKit`.
- **Removed `BaseEmailDto` Alias**:
  - Removed deprecated `BaseEmailDto` export. Use canonical `EmailTemplateDto`.

### Added

- **Auto Plain-Text Fallback in `sendRaw`**:
  - When sending raw or custom emails via `mailer.sendRaw({ to, subject, html })`, an accessible plain-text version is automatically generated from `html` if `text` is omitted.
- **Tree-Shakeable RFC 5322 Address Parser**:
  - Added standalone `parseEmailAddress(input: string): EmailAddress` utility for parsing `"Display Name <email@example.com>"` strings into `{ address, name }`.

### Migration Guide from 0.x

1. **Transport Initialization**:
   Replace `ZeptoMailSender` and `ZeptoMailConfig` with `ZeptoMailHttpSender` and `ZeptoMailHttpConfig`:
   ```ts
   // Before (0.x)
   import { ZeptoMailSender, ZeptoMailConfig } from 'ts-mailkit';
   const transport = new ZeptoMailSender({ apiToken, from });

   // After (1.0.0)
   import { ZeptoMailHttpSender, ZeptoMailHttpConfig } from 'ts-mailkit';
   const transport = new ZeptoMailHttpSender({ apiToken, from });
   ```

2. **Client Class & Type Aliases**:
   Replace `EmailService` with `MailKit`, and `BaseEmailDto` with `EmailTemplateDto`:
   ```ts
   // Before (0.x)
   import { EmailService, BaseEmailDto } from 'ts-mailkit';

   // After (1.0.0)
   import { MailKit, EmailTemplateDto } from 'ts-mailkit';
   ```

3. **Template Sending**:
   Replace positional arguments with the options object:
   ```ts
   // Before (0.x)
   await mailer.send('user@example.com', templateDto, 'User Name');

   // After (1.0.0)
   await mailer.send({
     to: 'user@example.com',
     template: templateDto,
     toName: 'User Name',
   });
   ```

4. **Simple Messages & Raw Dispatch**:
   Replace `sendSimpleMessage` with `sendRaw`:
   ```ts
   // Before (0.x)
   await mailer.sendSimpleMessage('user@example.com', 'Alert', 'Server rebooted');

   // After (1.0.0)
   await mailer.sendRaw({
     to: 'user@example.com',
     subject: 'Alert',
     html: '<p>Server rebooted</p>',
     // text is automatically derived if omitted!
   });
   ```
