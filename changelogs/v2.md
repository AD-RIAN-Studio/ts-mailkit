# Changelog - v2

All notable changes to `ts-mailkit` in version 2.x are documented here.

---

## [2.0.0] - 2026-09-20

### Breaking Changes

- **Removed `*_Legacy` positional factory methods**:
  - Removed `createEmailVerification_Legacy`, `createPasswordReset_Legacy`, `createSimpleMessage_Legacy`, `createNewsLetter_Legacy`, `create2FAEmail_Legacy`, `createMagicLinkEmail_Legacy` (instance + static).
  - Factory methods accept only Parameter Objects backed by canonical DTO types (`EmailVerificationParams`, `PasswordResetParams`, `SimpleMessageParams`, `NewsletterParams`, `TwoFactorParams`, `MagicLinkParams`).

### Migration Guide from 1.x

Replace positional calls with parameter objects:
```ts
// Before (1.x legacy)
EmailTemplateFactory.createEmailVerification_Legacy('Alex', url, '123456', 'Acme');

// After (2.0.0)
EmailTemplateFactory.createEmailVerification({ username: 'Alex', verificationUrl: url, otp: '123456', brandName: 'Acme' });
```
