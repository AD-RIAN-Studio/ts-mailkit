# Changelog - v3

All notable changes to `ts-mailkit` in version 3.x are documented here.

---

## [3.1.0] - 2026-10-30

### Added

- **Cpaas recipient limit guard**: `CpaasHttpSender` now rejects requests with more than 500 recipients (counted across `to`, `cc`, and `bcc`) before making any network request. It throws a `TransportError` including the total count and the limit. Exactly 500 recipients remain allowed.

---

## [3.0.0] - 2026-10-29

### Breaking Changes

- **Removed deprecated `MailKit.send()`**:
  - Use `MailKit.sendMail()` instead.
- **Removed `SendResult.response`**:
  - Use `SendResult.rawResponse` instead. All transports now expose the raw provider response only via `rawResponse`.
- **Removed deprecated ZeptoMail aliases**:
  - `ZeptoMailHttpSender` → use `CpaasHttpSender`.
  - `ZeptoMailHttpConfig` → use `CpaasHttpConfig`.
  - `ZeptoMailAddressObject` → use `CpaasAddressObject`.
  - `ZeptoMailRecipientWrapper` → use `CpaasRecipientWrapper`.
  - `ZeptoMailAttachmentPayload` → use `CpaasAttachmentPayload`.
  - `ZeptoMailSendPayload` → use `CpaasSendPayload`.
- **Removed the `src/transports/zeptomail/` re-export shim**:
  - Import from `src/transports/cpaas/` or the package root instead.

### Changed

- **Consolidated core option types**:
  - Merged `src/core/bulk-types.ts` into `src/core/types.ts`.
  - Shared fields now compose via reusable bases: `MailAddressOptions` (`from`, `cc`, `bcc`, `replyTo`, `attachments`), `MailMetadataOptions` (`headers`, `tags`, `metadata`), and `TrackingOptions` (`trackClicks`, `trackOpens`, `bounceAddress`, `clientReference`).
  - `BulkRecipient` extends `EmailAddress`; `SendTemplateOptions` extends the shared bases.
  - No runtime behavior change.

### Migration Guide from 2.1.x

```ts
// Before (2.1.x)
await mailer.send({ to: "user@example.com", template: dto });
const raw = result.response;
import { ZeptoMailHttpSender, ZeptoMailHttpConfig } from "ts-mailkit";

// After (3.0.0)
await mailer.sendMail({ to: "user@example.com", template: dto });
const raw = result.rawResponse;
import { CpaasHttpSender, CpaasHttpConfig } from "ts-mailkit";
```
